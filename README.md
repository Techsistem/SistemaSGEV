# SGEV - Sistema de Gestão de Vendas

**Status do Projeto:** 🚧 Em desenvolvimento

### 🎯 Objetivo do Software
O **SGEV** foi desenvolvido para automatizar e organizar os processos de cadastro e vendas da **Miratech**. O objetivo principal é substituir controles manuais por um sistema desktop robusto que garanta a integridade dos dados e agilize a consulta de informações de clientes e produtos, utilizando um banco de dados relacional.

### ⚙️ Funcionalidades do Sistema (Requisitos)

#### **Requisitos Funcionais**
* **Gestão de Clientes (CRUD):** Cadastro completo, consulta, edição e exclusão de clientes no banco de dados.
* **Busca Avançada:** Pesquisa dinâmica com preenchimento automático de formulários de edição através de uma `JTable`.
* **Persistência de Dados:** Integração total com MySQL para armazenamento permanente das informações.
* **Navegação entre Telas:** Interface independente que permite alternar entre os módulos de vendas e cadastros.

#### **Requisitos Não Funcionais**
* **Persistência ORM:** Uso do framework **Hibernate/JPA** para mapeamento objeto-relacional.
* **Interface Gráfica:** Desenvolvida em **Java Swing**.
* **Arquitetura:** Aplicação do padrão **DAO (Data Access Object)**.
* **Gerenciamento:** Projeto estruturado com **Maven**.

### 🛠️ Tecnologias Aplicadas
